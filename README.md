# 🛒 BuyCart

**BuyCart** is a modern Indian e-commerce website designed to provide a simple, fast, and user-friendly online shopping experience. Users can browse products, search for items, manage their cart and wishlist, sign in or sign up, and proceed through the checkout flow.

> **Project Type:** Frontend E-Commerce Prototype
> **Brand:** BuyCart
> **Technology:** HTML, CSS, JavaScript

---

## ✨ Features

* 🏠 Modern home page
* 🛍️ Product browsing and product listing
* 🔍 Product search
* 📂 Product categories
* 🛒 Add products to cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* 🗑️ Remove products from cart
* ❤️ Add and manage wishlist products
* 🔐 Sign In / Sign Up
* 💳 Checkout flow
* 🚚 Delivery information
* 📱 Responsive design for mobile and desktop
* 🧭 Easy navigation
* ⚡ Interactive user interface

## 🚀 How to Run the Project

### Option 1: Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The BuyCart website will open in your browser.

### Option 2: Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Use **Live Server** to run the website.
4. Open the displayed local URL in your browser.

## 🛒 Main User Flow

```text
Home
  ↓
Browse Products
  ↓
Select Product
  ↓
Add to Cart
  ↓
View Cart
  ↓
Proceed to Checkout
  ↓
Login / Sign Up (if not logged in)
  ↓
Checkout
```

If the user is already logged in, clicking **Proceed to Checkout** takes the user directly to the checkout process.
